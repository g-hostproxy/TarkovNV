FAQ

Does it touch the game?

No. TarkovNV never reads or modifies Escape From Tarkov. It changes your display's colour output through standard Windows and NVIDIA functions, the same way NVIDIA Control Panel does. Battlestate makes their own calls on third-party tools, so use your own judgement.

Windows says it's a virus / "protected your PC"

TarkovNV is free and not code-signed, so Windows is cautious about it. For "Windows protected your PC", click More info → Run anyway. Defender sometimes false-flags small unsigned apps too. The full source code is on GitHub so you can check it or build it yourself.

Does it work on AMD or Intel?

Yes. Gamma, brightness, contrast, shadows, highlights and the vibrance boost work on any GPU. NVIDIA cards also get the driver's own digital vibrance for the 0–100% range.

Will it lower my FPS?

No. The colour curve is applied by your display hardware after the game renders, so there's no FPS hit and no added input lag.

My changes aren't showing in-game

Use borderless windowed in Tarkov and turn HDR off in Windows display settings. For very strong night presets, click Unlock (admin) in the app once and restart your PC.
